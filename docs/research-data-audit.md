# 数据与回测审计基线

## 当前数据源与样本边界

当前网页通过 Cloudflare Worker 调用 Kraken `GET /0/public/OHLC`，对每个标的与周期使用最多 720 根最近 OHLCV，并在云端缓存 5 分钟。Kraken 官方说明该接口最后一根记录为当前未收盘周期，并且最多返回最近 720 根数据；即使传入更早的 `since`，也不能取得更早记录。[1]

因此，当前 1 分钟样本约为最近 12 小时，4 小时样本约为最近 120 天，日线样本约为最近 720 天。它适合交互研究与短窗口诊断，不足以单独支撑跨周期、跨市场的稳健性结论。

| 已发现问题 | 严谨处理要求 |
|---|---|
| 最后一根 K 线未收盘 | 回测与指标只使用已收盘 K 线，必须丢弃数据源返回的最后一根未提交记录。 |
| 当前仅取近期样本 | 页面明确显示样本开始/结束时间、K 线数量、数据源、缓存时间与数据哈希。 |
| 未验证 K 线连续性 | 检查相邻时间戳是否符合所选周期；发现缺口时在结果中标记并禁止给出稳健性评级。 |
| 交易成本仅有固定费率 | 显式记录费率、滑点、成交假设与每笔成本，禁止将其称作真实成交结果。 |
| 未区分样本内外 | 将可用历史按时间顺序分为训练段与验证段，分别显示绩效并对短样本给出警示。 |

## 采用的可复现研究口径

每一次运行应固定并展示：标的、数据源、周期、已收盘样本区间、样本量、策略配方、参数、成交价假设、费率、滑点、最大单笔风险、回测执行时间。结果仅解释为该固定口径下的历史模拟，并不代表未来收益。
